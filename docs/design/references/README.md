# Visual references

This directory stores owner-provided screenshots and HTML exports as design evidence.
They are not runtime code and do not override the Markdown contracts in `system`, the
Atomic levels, or the page specifications.

Every bundle keeps its `README.md`, `screen.png`, and `code.html` where supplied. A
bundle README with `artifact_source: visual_reference` is the traceability marker used
by design review and source extraction. Use the shared tokens and base contracts when
implementing the observed geometry; do not copy export colors or HTML into production.
