# Screen specifications

Create a directory only when implementing/reviewing that screen. Keep README.md as the durable artifact; screenshots are optional test evidence, not mandatory synchronized design exports.

Required sections:

1. Route, ticket/detail-design links, status.
2. Composition table: region → existing base path → props/variant. A missing base blocks screen composition until its contract/base exists.
3. Event → state/effect, including navigation, cancel, submit and error recovery.
4. Initial/loading/ready/empty/error/saving/disabled/read-only states.
5. Field validation, permission/source-of-truth and API dependencies.
6. User-visible copy and formatting conventions.
7. Automated/manual proof and residual gaps; no owner UAT sign-off invented by AI.
