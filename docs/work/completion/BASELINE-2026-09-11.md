## Environment Finding: Redis Host-Port Collision

Initial `docker compose up -d --wait postgres redis s3` failed because MyPocket hard-coded host port `6379`. Evidence showed the port belongs to the existing `dev-env` container `/redis`, which was healthy and must not be stopped or repurposed.

RED proof:

```text
MYPOCKET_REDIS_HOST_PORT=6380 docker compose config | rg 'published: "6380"'
exit 1
```

Minimal correction: `compose.yaml` now maps `${MYPOCKET_REDIS_HOST_PORT:-6380}:6379`; internal containers still use `redis:6379`.

GREEN proof:

```text
MYPOCKET_REDIS_HOST_PORT=6380 docker compose config
published: "6380"
docker compose up -d --wait redis
mypocket-redis-1: healthy, 0.0.0.0:6380->6379/tcp
```

PostgreSQL is healthy on `127.0.0.1:55433`; LocalStack S3 is healthy on `127.0.0.1:4567`; the isolated MyPocket Redis is healthy on `127.0.0.1:6380`.
