# Danh sách Entities

## Identity

| Bảng | Mục đích | Ghi chú |
|------|----------|---------|
| `users` | Danh tính Google | Unique provider subject; không lưu token |

## Finance Core

| Bảng | Mục đích | Ghi chú |
|------|----------|---------|
| `wallets` | Ví tiền | VND-first; credit metadata; versioned; archived |
| `categories` | Danh mục 2 cấp | System rows locked; user rows archived |
| `wallet_category_settings` | Kích hoạt category theo wallet | Composite unique |
| `transactions` | Giao dịch đã xác nhận | Positive integer; type quyết định balance effect |
| `transaction_drafts` | Bản nháp | Không ảnh hưởng balance |
| `receipt_objects` | Metadata ảnh hoá đơn | S3 key, checksum, size, content type |

## Planning

| Bảng | Mục đích | Ghi chú |
|------|----------|---------|
| `budgets` | Ngân sách | Weekly/monthly/quarterly/yearly/custom |
| `budget_categories` | Category scope cho budget | Composite unique |
| `budget_alerts` | Alert 80%/100% | Dedupe theo budget/threshold/period |
| `events` | Sự kiện | Versioned; archived |
| `event_transactions` | Link event-transaction | Composite unique |
| `recurring_schedules` | Lịch lặp | Worker emit drafts |
| `recurring_occurrences` | Ledger occurrences | Unique per schedule/key |
| `obligations` | Vay/nợ | Principal, counterparty, due date |
| `obligation_repayments` | Link repayment-transaction | Không vượt quá principal |

## Portfolio

| Bảng | Mục đích | Ghi chú |
|------|----------|---------|
| `asset_positions` | Tài sản đầu tư | Separate từ wallets; VND reporting |
| `asset_trades` | Lệnh mua/bán | Decimal quantity; integer VND |
| `asset_price_history` | Lịch sử giá | Append-only |

## Sync

| Bảng | Mục đích | Ghi chú |
|------|----------|---------|
| `sync_mutations` | Idempotency ledger | Unique client mutation ID |
| `sync_changes` | Change feed | Monotonic per-user cursor |
| `sync_conflicts` | Xung đột | Resolution lifecycle |

## Notifications

| Bảng | Mục đích | Ghi chú |
|------|----------|---------|
| `notifications` | In-app notice | Read state; related entity |
| `push_subscriptions` | Web Push | Capped retry; expiry cleanup |

## Ingestion

| Bảng | Mục đích | Ghi chú |
|------|----------|---------|
| `webhook_sources` | Bank webhook sender | Encrypted HMAC |
| `webhook_events` | Replay/dedup ledger | Unique source event |
| `ai_conversations` | AI chat container | Provider metadata |
| `ai_messages` | Message + draft links | Multi-transaction result |

## Operations

| Bảng | Mục đích | Ghi chú |
|------|----------|---------|
| `api_keys` | API key cho third-party | HMAC hash; revocable |
| `audit_events` | Audit log | Append-only; restricted read |
| `job_leases` | Worker ownership | Bounded leases |
| `exports` | Export job | Expiring snapshot |
