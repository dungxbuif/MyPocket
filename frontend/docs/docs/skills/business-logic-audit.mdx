# Skill audit logic nghiệp vụ

MyPocket phát hành một skill cùng source code để AI agent có thể audit lại finance, planning, analytics, sync, phân quyền, API key và Redis theo cùng một chuẩn:

```text
.agents/skills/auditing-mypocket-business-logic/SKILL.md
```

Agent cần đọc `AGENTS.md` trước, sau đó đọc skill trên khi yêu cầu liên quan tới số dư, ví, giao dịch, chuyển ví, báo cáo, obligation, recurring draft, đồng bộ offline, tích hợp API key hoặc phân quyền dữ liệu người dùng.

## Skill buộc agent kiểm tra gì?

| Khu vực | Bất biến phải có bằng chứng |
| --- | --- |
| Giao dịch | Create/edit/archive phải áp dụng hoặc đảo đúng delta; chống tràn `int64` |
| Chuyển ví | Trừ ví nguồn và cộng ví đích trong cùng transaction; không tính là thu/chi |
| Báo cáo | Đúng khoảng ngày theo `Asia/Ho_Chi_Minh`, filter ví, archived/excluded và loại giao dịch |
| Version/retry | `base_version` cũ trả `409 VERSION_CONFLICT`; idempotency không bỏ sót field nghiệp vụ |
| Planning | Repayment đúng chiều và không vượt principal; recurring tuân thủ rule giao dịch; draft pending không đổi số dư |
| Sync | Mutation, change feed và receipt có tính at-most-once khi crash hoặc retry đồng thời |
| API key | Bearer key có cùng business contract, không cần CSRF, chỉ thấy dữ liệu chủ key và bị chặn sau revoke |
| Redis/audit | Redis không phải nguồn phân quyền chính; revoke làm mất cache; mutation nhạy cảm có audit an toàn |

## Quy trình bắt buộc

1. Nêu bất biến bằng một câu có thể kiểm chứng.
2. Trace dọc từ request DTO, auth, validation, repository/DB lock đến response và caller frontend/offline.
3. Viết test nhỏ nhất và quan sát test thất bại đúng nguyên nhân (**RED**).
4. Sửa tại boundary dùng chung, không chỉ che lỗi ở UI.
5. Chạy test focused, package suite và flow API/browser liên quan (**GREEN**).
6. Cập nhật validation matrix, hồ sơ evidence, changelog và trang API bị ảnh hưởng.

Một build local không đồng nghĩa đã deploy. Tài liệu audit luôn phải ghi rõ trạng thái `local-only`, `staged` hoặc `production-verified`.

## Cách gọi từ agent

Ví dụ prompt:

```text
Đọc .agents/skills/auditing-mypocket-business-logic/SKILL.md và audit flow
chuyển tiền giữa hai ví, gồm create/edit/archive, report exclusion, API key,
stale version và concurrent retry. Sửa lỗi bằng test RED-GREEN và cập nhật docs.
```

Skill có catalog bất biến tại `references/invariants.md` và ba kịch bản đánh giá khả năng áp dụng tại `references/evaluations.md`. Chúng được version cùng code để contract audit thay đổi đồng bộ với hệ thống.

## Trạng thái kiểm chứng hiện tại

Đợt audit 10/09/2026 đã bổ sung bằng chứng local cho vòng đời ví/giao dịch/chuyển ví, loại transfer khỏi cash-flow report, chống overflow kế toán/analytics, stale wallet/transaction/planning/category version, recurring payload validation, repayment direction/locking, receipt preservation/idempotency, ngày giao dịch mặc định theo giờ Việt Nam, API-key revoke khi Redis stale và offline category activation. Backend đầy đủ, race detector cho các package trọng yếu, 158 frontend tests, 27 browser scenarios và Docusaurus build đều đã qua.

ADR-008 đã triển khai và kiểm chứng local: domain/feed/receipt commit nguyên tử, direct finance/portfolio và xác nhận draft phát feed, retry giữ nguyên mutation ID. Nâng cấp cần migration 0012 và full resync vì feed thiếu trước đây không được backfill. Contract `include_in_total`, ví archived và last-write-wins của wallet-category setting được mô tả theo code hiện tại. Chưa deploy bản sửa này.
