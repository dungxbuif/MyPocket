# Analytics & Reports API

Đối chiếu với `httpapi/analytics.go` và `analytics/types.go` ngày 2026-09-08. Các endpoint nhận cookie hoặc bearer API key.

## Authentication

- Các route báo cáo là read-only.
- Sử dụng cookie (`mypocket_auth`) hoặc Bearer API key.
- Permission là owner-scope: `user_id` lấy từ context xác thực; query của user khác không trả dữ liệu.

## Query và envelope

```http
GET /api/v1/dashboard?from=2026-09-01&to=2026-09-30&wallet_id=...
GET /api/v1/reports/cash-flow?from=2026-09-01&to=2026-09-30&wallet_id=...
GET /api/v1/reports/categories?from=2026-09-01&to=2026-09-30&wallet_id=...
GET /api/v1/reports/daily?from=2026-09-01&to=2026-09-30&wallet_id=...
GET /api/v1/reports/comparison?from=2026-09-01&to=2026-09-30&wallet_id=...
GET /api/v1/reports/cumulative?from=2026-09-01&to=2026-09-30&wallet_id=...
GET /api/v1/reports/insider?from=2026-09-01&to=2026-09-30&wallet_id=...
```

Analytics nhận `from/to`, **không dùng** `date_from/date_to`. Ngày theo Asia/Ho_Chi_Minh; `to` bao gồm hết ngày. Mặc định là tháng hiện tại, riêng cumulative bỏ cả hai ngày mở rộng từ đầu tháng cách đây hai tháng đến cuối tháng hiện tại.

Envelope chung:

```json
{
  "status": "ok",
  "report": {},
  "generated_at": "2026-09-08T00:00:00Z",
  "timezone": "Asia/Ho_Chi_Minh",
  "from": "2026-09-01",
  "to": "2026-09-30",
  "data_version": 1,
  "correlation_id": "req_example"
}
```

Nội dung `report` tùy endpoint, không phải key `dashboard`.

## Dashboard

Payload trong `report` gồm:

- `summary`: income_vnd, expense_vnd, net_income_vnd, daily_average_vnd và metadata.
- `net_worth_vnd`, `wallet_net_worth_vnd`, `investment_market_value_vnd`, `combined_net_worth_vnd`, `missing_asset_price_count`.
- `wallets`, `recent_transactions`.

Không có `savings_vnd`. `include_in_total=false` chỉ loại ví khỏi tổng số dư/net worth. Thu/chi vẫn là báo cáo theo giao dịch và vẫn gồm giao dịch reportable của ví đó; dùng `excluded_from_reports=true` trên giao dịch để loại khỏi báo cáo.

## Reports

| Loại | Dữ liệu trong report | Giới hạn |
| --- | --- | --- |
| cash-flow, daily | summary, daily | Các dòng ngày gồm income, expense, net, cumulative_net_vnd. |
| categories | summary, categories | Chỉ chi tiêu, roll-up cha; chưa có income, flat tree hoặc category_id filter. |
| comparison | summary, prior | Kỳ trước cùng độ dài, không bảo đảm là tháng lịch trước. |
| cumulative | summary, daily | Cộng dồn thu nhập ròng, không phải trung bình ba tháng Money Lover. |
| insider | Payload riêng | Mới có tóm tắt Home. |

Summary chỉ tính income/expense không bị excluded_from_reports. Chưa có opening/ending balance, Other, member reports hoặc full report drilldown.

## Money Insider

Ví dụ payload bên trong `report`:

```json
{
  "selected_category": {
    "id": "00000000-0000-0000-0000-000000000001",
    "name": "Ăn uống",
    "transaction_count": 3
  },
  "spent_vnd": 300000,
  "elapsed_days": 8,
  "average_daily_vnd": 37500,
  "prior_average_daily_vnd": 25000,
  "change_percent": 50,
  "not_comparable": false,
  "generated_at": "2026-09-08T00:00:00Z",
  "timezone": "Asia/Ho_Chi_Minh",
  "from": "2026-09-01",
  "to": "2026-09-30",
  "data_version": 1
}
```

Chọn danh mục nhiều giao dịch nhất, hòa thì xét tổng tiền rồi ID. `selected_category` và `change_percent` có thể vắng; kiểm tra `not_comparable` trước khi hiển thị tỷ lệ.

Các field `projected_spending_vnd`, `budget_vnd`, `budget_progress_percent`, `top_expenses` và series sáu kỳ **chưa được trả về**.

## Search

```http
GET /api/v1/search?q=keyword
```

Trả `{status, results, stale, correlation_id}`; mỗi result có `kind`, `id`, `label` và `detail` optional. Đây là tìm kiếm nhóm thực thể, không phải full advanced report filter.

### Phản hồi tìm kiếm trên web

Từ bản cập nhật ngày 2026-09-09, giao diện yêu cầu ít nhất hai ký tự và phân biệt đang tải, kết quả rỗng sau phản hồi thành công, lỗi có nút thử lại, và trạng thái cần kết nối mạng. Lỗi không xoá từ khoá. Phản hồi cũ bị bỏ qua khi đổi/xoá từ khoá, đóng bảng tìm kiếm hoặc đăng xuất. Đây là thay đổi frontend, không thêm endpoint hay bộ lọc API.

Xem [phạm vi và giới hạn bản cập nhật](/docs/updates/2026-09-09); nhãn độ mới của kết quả cache và điều hướng chi tiết đầy đủ vẫn chưa được xác nhận hoàn tất.
