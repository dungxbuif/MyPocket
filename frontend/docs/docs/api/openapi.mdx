# OpenAPI máy đọc

Contract chính thức được phục vụ công khai tại [`/api/v1/openapi.json`](https://money.dungxbuif.com/api/v1/openapi.json). CI kiểm tra mỗi operation có security, error envelope, correlation ID, rate-limit response và `Idempotency-Key` khi route yêu cầu.

```bash
curl https://money.dungxbuif.com/api/v1/openapi.json > mypocket-openapi.json
```

Bearer API key bị giới hạn mặc định 120 request/phút theo cặp user/key. Khi vượt giới hạn, API trả `429` và `Retry-After`. Nếu Redis không thể cưỡng chế giới hạn, Bearer request trả `503`; cookie browser không phụ thuộc limiter này.

Các snippet YAML theo domain là ví dụ, không thay thế contract tổng thể này.
