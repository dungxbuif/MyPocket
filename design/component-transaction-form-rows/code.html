Cấu Trúc Hàng Dữ Liệu (Row Item Anatomy)

Được thiết kế dạng slot-based layout nhằm đảm bảo tính đồng bộ trên tất cả màn hình nhập liệu.

Left Slot
Kích thước cố định (36px - 40px): Chứa Brand Logo (Techcombank/ACB), Currency Unit Tag (VND), Category Glyph hoặc System Icon (Vị trí, Nhắc nhở, Ghi chú).
Center Slot
Nội dung động (Flex 1): Gồm Label định danh, Input text tự do, hoặc Large Amount Typography hiển thị số tiền tương phản cao.
Right Slot
Tương tác phụ & Chỉ báo: Chevron phải (>) để mở Sub-sheet/Modal, Date Stepper (< Date >), hoặc Switch Toggle on/off.
