Cấu Trúc Giải Phẫu Component (Anatomy)

v2.4 Production

Card phân cấp lồng nhau được tối ưu để hiển thị mối liên kết chặt chẽ giữa Danh Mục Mẹ và các Mục Phụ Thuộc, loại bỏ sự rối mắt qua ngôn ngữ trực quan đường kẻ cây (Tree Branching Line) thay vì thụt lề vô định hình.

1. Content Origin Anchor

Đường phân cấp xuất phát dưới chân vùng nội dung/text thay vì neo vào icon cha, tạo khoảng thở thoáng và mạch lạc.

2. Tree Branch Connector

Đường kẻ dọc left: 66px kết hợp node cong 90 độ nối êm ái sang từng mục con.

3. Child Indentation

Thụt lề con pl-16 (64px) giúp các thẻ con nằm gọn gàng bên phải đường phân cấp dọc.

4. Micro Subtext

Mô tả phụ "Hoạt động trong 3 ví" màu xám nhạt với độ phân cấp font 11px/10px.

Hướng Dẫn Tái Sử Dụng (Usage Guidelines)

Copy-paste Ready
