# MyPocket — Tài liệu kỹ thuật

**MyPocket** là ứng dụng quản lý tài chính cá nhân (PWA) dành cho homelab, với kiến trúc offline-first, đồng bộ real-time qua PostgreSQL.

## Kiến trúc tổng quan

```mermaid
graph TB
    subgraph Frontend
        PWA[React PWA + IndexedDB]
        SW[Service Worker]
    end
    subgraph Backend
        API[Go API<br/>:8080]
        Worker[Go Worker<br/>recurring/notifications]
    end
    subgraph Storage
        PG[(PostgreSQL)]
        S3[S3-compatible<br/>receipts/exports]
        R[(Redis<br/>auth cache)]
    end
    PWA -->|HTTP/JSON| API
    PWA --> SW
    API --> PG
    API --> S3
    API --> R
    Worker --> PG
    Worker -->|VAPID| Push[Web Push]
```

## Công nghệ

| Layer | Công nghệ |
|-------|-----------|
| **Frontend** | React 19 + TypeScript + Vite 7 + Tailwind CSS v4 |
| **Backend** | Go 1.24 modular monolith (API + Worker) |
| **Database** | PostgreSQL 16 (source of truth) |
| **Object storage** | S3-compatible (presigned URLs) |
| **Cache** | Redis 7 (auth cache, API key lookup) |
| **Auth** | Google OAuth + stateless signed cookie + API keys |
| **Push** | Web Push (VAPID) via service worker |

## Phạm vi hiện tại

MyPocket có ví, danh mục, giao dịch, chuyển ví, đồng bộ offline, ngân sách, planning, báo cáo, tài sản, import/export, vòng đời tài khoản và trợ lý review-first. Ảnh gửi cho trợ lý có thể được xử lý bằng OCR Platform bên thứ ba; OCR không phải dịch vụ ngân hàng và không tự ghi sổ.

Xem [cập nhật 09/09/2026 và giới hạn](/docs/updates/2026-09-09) để biết thay đổi web mới nhất, bằng chứng kiểm thử và các phần chưa hoàn tất. Ảnh hoá đơn/PWA offline trên iPhone thật vẫn cần kiểm chứng.
