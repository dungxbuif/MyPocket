Context: current context/backlog/standards and the approved R0 direction; mounted App search, analytics search adapter and existing shared error/input/card components. Existing callback catches every failure as an empty array, displays empty before the request completes and allows older promises to overwrite newer queries. Query state also outlives the panel. These are source-confirmed paths; regression tests must reproduce them before changes.

Implementation: isolate the existing SearchPanel in its own component, keep query in App to preserve it across panel toggling. Panel owns request state and effect cleanup invalidates obsolete completions on query/connectivity/owner/unmount changes. Key by owner and clear query on unauthenticated state. Render empty only after a successful current query; loading and safe retryable OperationError are distinct. Reuse Card, SearchInputField and shared error/buttons; label the shared clear button. Offline search remains unavailable (no new local search engine); explicitly state this instead of claiming no matching data. Preserve the analytics adapter's existing transport-only cache fallback, API and minimum two-character query behavior.

Alternatives rejected: retaining catch-to-empty; global asynchronous state for an unmounted panel; introducing a new search API, query library or broad UI redesign. No user data mutations, new dependencies, accounting or runtime changes. Current dirty checkout retained; no unrelated edits staged or reverted.

Verification: real App + fetch-boundary failures/deferred responses; failure/retry, pending/empty, stale success/failure, clear/close/offline invalidation. Browser HTTP rejection/retry with real fixture search data; full frontend unit/typecheck/build and Chrome regressions. Keep unrelated WebKit receipt/PWA failures separate. Docs review reconciles context/backlog/inventory/validation/changelog. Requirements/API/ERD/security/architecture/ADR unchanged unless a new contract is actually needed. Human device acceptance remains distinct from automated proof.
