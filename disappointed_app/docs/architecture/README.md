# Architecture Docs

This folder contains master technical documentation.

## Files

- `ARCHITECTURE.md`: system structure and boundaries.
- `API.md`: public endpoints, events, and contracts.
- `ERD.md`: entities, tables, relationships, and migrations.
- `INTEGRATIONS.md`: external systems and dependencies.
- `SDD.md`: approved system design, invariants, delivery slices, and change-control boundaries.

Agents must reconcile these files after code changes that affect architecture, APIs, data, integrations, or runtime behavior.
