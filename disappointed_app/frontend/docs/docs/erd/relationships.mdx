# Relationships

## Ownership

Mọi bảng user-owned đều có `user_id` — tất cả foreign key đều trỏ về cùng user:

```
users ──┐1:N── wallets
users ──┐1:N── categories
users ──┐1:N── transactions
users ──┐1:N── budgets
users ──┐1:N── asset_positions
...
```

## Category Hierarchy

```
categories (parent) ──┐1:N── categories (children)
```

- Service enforce `depth <= 2`
- System categories (is_system = true) không thể sửa/xoá

## Wallet → Transaction

```
wallets ──┐1:N── transactions (source_wallet_id)
transactions ──┐??:1── wallets (destination_wallet_id, cho transfer)
```

## Budget → Category

```
budgets ──┐1:N── budget_categories ──┐N:1── categories
```

## Budget → Transaction/Draft/Schedule

```
budgets ──┐1:N── transactions (budget_id, expense only)
budgets ──┐1:N── transaction_drafts (budget_id, expense only)
budgets ──┐1:N── recurring_schedules (budget_id, expense only)
```

Budget progress reads explicit `transactions.budget_id`; category links are UI/filter metadata.

## Event → Transaction

```
events ──┐1:N── event_transactions ──┐N:1── transactions
```

- Transactions bị exclude khỏi report vẫn link được

## Asset → Trades + Prices

```
asset_positions ──┐1:N── asset_trades
asset_positions ──┐1:N── asset_price_history
```

- Composite `(asset_id, user_id)` FK

## Sync

```
sync_mutations ──┐1:1── transaction (khi mutation là create transaction)
sync_changes ── dòng change feed, mỗi user một cursor riêng
```

## Agent → OCR tool → Draft

```
agent_runs ──┐1:N── agent_tool_runs
agent_runs ──┐0:1── transaction_drafts ──┐0:1── transactions
```

OCR output is scoped to the owning run. The draft has no accounting effect until explicit confirmation. Bank/webhook ingestion is not part of the current schema.
