# Categories API

> Đối chiếu code 2026-09-10: create nhận `kind`, `name`, `parent_id`; update nhận `name`, `parent_id`, `base_version`. Chưa có API merge category hoặc cascade activation cha/con. Các snippet YAML là mô tả từng phần, chưa phải một OpenAPI hoàn chỉnh đã validate.

## OpenAPI Spec

```yaml
openapi: 3.0.0
paths:
  /api/v1/categories:
    get:
      summary: Danh sách danh mục
      security: [{ cookieAuth: [], bearerAuth: [] }]
      responses:
        "200":
          content:
            application/json:
              schema:
                type: object
                properties:
                  categories:
                    type: array
                    items: { $ref: "#/components/schemas/Category" }
    post:
      summary: Tạo danh mục
      security: [{ cookieAuth: [], csrf: [] }, { bearerAuth: [] }]
      requestBody:
        required: true
        content:
          application/json:
            schema: { $ref: "#/components/schemas/CreateCategoryInput" }
      responses:
        "201": { description: "Created" }
  /api/v1/categories/{id}:
    patch:
      summary: Sửa danh mục
      security: [{ cookieAuth: [], csrf: [] }, { bearerAuth: [] }]
      responses:
        "200": { description: "OK" }
        "400": { description: "Cannot edit system category" }
  /api/v1/categories/{id}/archive:
    post:
      summary: Lưu trữ danh mục
      security: [{ cookieAuth: [], csrf: [] }, { bearerAuth: [] }]
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [base_version]
              properties:
                base_version: { type: integer, minimum: 1 }
      responses:
        "200": { description: "OK" }
        "409": { description: "VERSION_CONFLICT" }
  /api/v1/wallets/{wallet_id}/categories/{category_id}:
    put:
      summary: Kích hoạt/tắt category trong wallet
      security: [{ cookieAuth: [], csrf: [] }, { bearerAuth: [] }]
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              properties:
                active: { type: boolean }
      responses:
        "200": { description: "OK" }
components:
  schemas:
    Category:
      type: object
      properties:
        id: { type: string, format: uuid }
        kind: { type: string, enum: ["expense", "income", "debt"] }
        name: { type: string }
        parent_id: { type: string, format: uuid, nullable: true }
        system_key: { type: string, nullable: true }
        is_system: { type: boolean }
        version: { type: integer }
    CreateCategoryInput:
      type: object
      required: [kind, name]
      properties:
        kind: { type: string, enum: ["expense", "income", "debt"] }
        name: { type: string, minLength: 1 }
        parent_id: { type: string, format: uuid, nullable: true }
```

## System seeds

| Kind | system_key | Name |
|------|-----------|------|
| expense | `expense_food` | Ăn uống |
| expense | `expense_shopping` | Mua sắm |
| expense | `expense_transport` | Di chuyển |
| income | `income_salary` | Lương |
| income | `income_bonus` | Thưởng |
| debt | `debt_loan` | Vay nợ |

## Rules

- System categories (`is_system = true`) **không thể** sửa, xoá, archive
- User-created categories có `user_id`, `is_system = false`
- Catalog seed và category của người dùng hỗ trợ cây tối đa 2 cấp; cha/con phải cùng `kind` và cùng scope chủ sở hữu.
- Mỗi category có thể active/inactive riêng theo từng wallet
- `PUT /wallets/{wallet_id}/categories/{category_id}` để toggle active state
- Sửa và archive category tự tạo bắt buộc gửi `base_version`; version cũ trả `409 VERSION_CONFLICT` và không ghi đè/archive trạng thái mới hơn.
- Wallet-category activation hiện là lệnh đặt trạng thái idempotent (`active: true|false`), chưa có version riêng cho row setting.
