# Hoàn thiện local trước release

Build hiện tại bổ sung public OpenAPI route coverage, API-key rate limiting qua Redis, authorization inventory, import/export/account lifecycle, Agent OpenAI-compatible review-first, OCR Platform như image tool bên thứ ba, và giao diện responsive đơn sắc dựa trên base components.

Kiểm thử local đã chạy backend race/integration với PostgreSQL/Redis/S3, 177 frontend tests, production build và 105 Playwright E2E trên desktop Chromium, mobile Chromium, mobile WebKit. Các luồng E2E gồm ví/danh mục/giao dịch, chuyển ví không tính báo cáo, ngân sách/planning, báo cáo, offline sync/conflict, receipt, agent text/image, API key/revoke và user isolation.

## Chưa được phép suy diễn

- UAT iPhone/Safari thật còn pending và là release blocker.
- Provider smoke production cho OpenAI-compatible API và OCR Platform còn phải chạy với secret production.
- Không có tích hợp ngân hàng trong scope hiện tại.
- Trang này mô tả commit local; production chỉ được xác nhận sau release evidence và smoke URL công khai.
